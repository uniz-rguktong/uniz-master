# Landing site

The public college site is `apps/uniz-landing`, run locally on port 5174 for this capture. It is separate from the exam-cell portal on port 5173.

The header links Institute, Academics, Departments, and Notifications. “UniZ Portal” leaves the marketing site for the portal. Developers, the Android app, and the iOS app are in the top bar.

## Pages captured

Home, About RGUKT, Campus Life, Education System, Governing Council, RTI, SC/ST Cell, Academic Programs, Academic Calendar, Academic Regulations, Curricula, CSE, Civil, ECE, News, Tenders, Careers, the 404 page, and the narrow-viewport menu.

News, Tenders, and Careers render their empty states because the landing API was not part of this local run. The pages themselves load.

The first attempt to screenshot the site showed Vite’s PostCSS overlay, because the `lightningcss` Linux binary was not installed. The binary was installed locally and the landing screenshots were taken again. Those overlay images were replaced.
