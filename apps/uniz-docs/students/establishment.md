# Establishment

Status: live

Staff master for faculty and admin staff, run by the webmaster, director and dean.

- Staff list built from existing faculty and admin profiles, with search
- Staff record per person: employee id, designation, department, cadre, employment type, joining date, status
- Designation counts
- Service history: joined, promotion, transfer, increment, deputation, retired. A promotion updates the designation and a transfer updates the department.
- Leave balances for the current year are read from the leave module

Flag: `FEATURE_ESTABLISHMENT`. When the flag is off the page shows "Establishment is turned off". No keys needed.
