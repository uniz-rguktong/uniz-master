---
title: "Grievances"
description: "Submit student grievances, list and resolve concerns (SWO), with email and push notifications."
---

<Info>
  Base URL: `https://api-uniz.rguktong.in/api/v1/grievance`
</Info>

The grievance module lets students raise welfare concerns. The **SWO** (Student Welfare Officer), **director**, and **admin** roles can review the queue and mark items resolved. Verified (non-anonymous) students receive email and push notification on resolution.

---

## Submit a grievance

`POST /grievance/submit`

**Auth required:** Student

### Request body

| Field | Type | Required | Notes |
| ----- | ---- | -------- | ----- |
| `category` | string | Yes | e.g. `Hostel`, `Mess`, `Academic`, `Other` |
| `description` | string | Yes | Minimum 10 characters |
| `isAnonymous` | boolean | No | Default `false` |

```bash
curl --request POST \
  --url https://api-uniz.rguktong.in/api/v1/grievance/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "category": "Hostel",
    "description": "Water supply issue on Block I third floor since Monday.",
    "isAnonymous": false
  }'
```

**200 OK**

```json
{
  "success": true,
  "message": "Grievance submitted successfully"
}
```

- SWO receives a push alert for new submissions.
- Non-anonymous students receive a confirmation push with a short ticket reference.

## List grievances (SWO / admin)

`GET /grievance/list`

**Auth required:** `swo`, `director`, or `admin`

### Query parameters

| Parameter | Default | Description |
| --------- | ------- | ----------- |
| `page` | `1` | Page number |
| `limit` | `20` | Items per page |

```bash
curl --request GET \
  --url 'https://api-uniz.rguktong.in/api/v1/grievance/list?page=1&limit=20' \
  --header 'Authorization: Bearer <token>'
```

**200 OK**

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "studentId": "O210008",
      "username": "O210008",
      "studentName": "DESU SreeCharan",
      "studentEmail": "o210008@rguktong.ac.in",
      "studentBranch": "CSE",
      "studentYear": "E3",
      "category": "Hostel",
      "description": "Water supply issue on Block I third floor since Monday.",
      "isAnonymous": false,
      "status": "Pending",
      "resolvedBy": null,
      "resolvedAt": null,
      "createdAt": "2026-06-26T10:00:00.000Z"
    }
  ],
  "pagination": { "page": 1, "limit": 20, "total": 1, "totalPages": 1 }
}
```

List responses enrich non-anonymous grievances with student profile data from the user service.

## Resolve a grievance

`PATCH /grievance/:id/resolve`

Marks a grievance as resolved. For verified students, sends:

- Email: *"Your concern about {category} has been received and we will resolve it."*
- Push notification with the same message

**Auth required:** `swo`, `director`, or `admin`

```bash
curl --request PATCH \
  --url https://api-uniz.rguktong.in/api/v1/grievance/uuid-here/resolve \
  --header 'Authorization: Bearer <token>'
```

**200 OK**

```json
{
  "success": true,
  "message": "Grievance resolved and student notified by email.",
  "emailSent": true,
  "data": {
    "id": "uuid",
    "status": "Resolved",
    "resolvedBy": "swo",
    "resolvedAt": "2026-06-26T12:00:00.000Z"
  }
}
```

**400** — already resolved.

## Delete grievances

| Endpoint | Method | Access | Purpose |
| -------- | ------ | ------ | ------- |
| `/grievance/:id` | DELETE | SWO / director / admin | Delete one grievance |
| `/grievance/all` | DELETE | SWO / director / admin | Clear entire grievance queue |

<Warning>
  `DELETE /grievance/all` is destructive and removes every grievance record.
</Warning>
